# Card & Krueger
---

This project started as a replication for a Statistical & Machine Learning course and kept going. Card & Krueger (1994) found that New Jersey's 1992 minimum wage increase did not reduce fast-food employment, overturning the theoretical assumption.

Employment rose by about 2.8 FTE per store relative to Pennsylvania — and a dose-response specification reaches the same conclusion without relying on the cross-state comparison.

A more in-depth explanation of how this was built is available [here.](https://mcgeever1.github.io/projects/card-krueger)
